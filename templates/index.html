About Handwritten Digit Recognition

This system is a deep learning digit recognition application powered by a Convolutional Neural Network (CNN) trained on the classic MNIST dataset.

  • Model Architecture: 2D CNN with 2 Convolutional blocks, Max Pooling, Dropout, and Dense layers.
  • Parameters: 225,034 trainable weights.
  • Test Accuracy: 99.10% on the official 10,000-image test set.
  • Persistence: SQLite database with full search, filter, and CSV export.
  • Interactive Features: Eraser, Redo, Auto-predict, Chart.js analytics, Feedback collection, and Digit Challenge mode.
